## Limits and known gaps

- **Read-only bit:** git does not track it, so `recovered/` is writable in a checkout. Immutability is enforced here by the
  `SHA256SUMS` test plus code review. The original assertion still runs with `GF_ENFORCE_READONLY=1` on a locked copy
  (it fails on a normal checkout, by design of the skip).
- **Wrench Mode** is still wired only into the admin test route, not the public repair guide pages.
- **Reconstructed behavior that is NEW, not recovered:** the 3-resubmission metadata retry cap, strict Hermes/ChatGPT
  independent-reviewer identity checks, and the ownership posture. See `README-RECONSTRUCTED.md`.
- **Lint scope:** `eslint.config.mjs` ignores this directory (24 unused-import warnings in reconstructed tests; recovered
  copies must stay byte-frozen). It is still type-checked by `tsc` through the root tsconfig.
- Original `scripts/visuals/*.mjs` need `sharp` at runtime; it resolved in this checkout.
- **History still contains a laptop username:** `124f561` includes the path removed in the cleanup pass (see `REDACTION-LOG.md`). Only a history rewrite would remove it; not done, needs owner approval. `APPLY-POLISH.md` and `APPLY-THIS-FIRST.md` on `main` also contain it (pre-existing, outside this branch).
